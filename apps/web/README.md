# ENGECOM — Gestão de Segurança (Frontend)

React + TypeScript + Vite + Tailwind CSS. Consome a API em `apps/api` (proxy `/api` ->
`http://localhost:4000` configurado em `vite.config.ts`).

Veja o README na raiz do monorepo para instruções completas de setup.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build       # build de produção em dist/
npm run typecheck
```
